- **توليد صور وفيديو** بالذكاء الاصطناعي
- **نظام ذاكرة** يتعلّم تفضيلاتك

- **بث الاستجابات** في الوقت الفعلي (streaming)
- **وضعين فاتح وداكن**

## التثبيت


إذا حصلت على المشروع كملف ZIP:

## التشغيل

### 1. إعداد ملف البيئة

أنشئ ملف `.env` في المجلد الرئيسي:
```bash
cp .env.example .env
```

أو أنشئه يدوياً بالمحتوى التالي:
```env
# قاعدة البيانات (SQLite)
DATABASE_URL="file:./db/custom.db"
```

### 2. تهيئة قاعدة البيانات

```bash
# إنشاء الجداول في قاعدة البيانات
bun run db:push

# أو باستخدام npm
npm run db:push
```

### 3. تشغيل خادم التطوير

```bash
# باستخدام Bun
bun run dev

# أو باستخدام npm
npm run dev
```

سيبدأ الخادم على: **http://localhost:3000**

افتح المتصفح وانتقل إلى العنوان أعلاه. ✅

### 4. بناء الإنتاج (اختياري)

```bash
# بناء المشروع
bun run build

# تشغيل النسخة المبنية
bun run start
```

## الإعدادات

### مفاتيح API الخارجية (اختياري)

لتفعيل التكامل مع المنصات، افتح التطبيق واضغط على أيقونة 🔑 (Key) في الأعلى:

#### 📺 YouTube Data API
1. اذهب إلى [Google Cloud Console](https://console.cloud.google.com/)
2. أنشئ مشروعاً جديداً
3. فعّل "YouTube Data API v3" من المكتبة
4. أنشئ API Key من Credentials
5. الصق المفتاح في التطبيق

#### 🤖 Telegram Bot
1. افتح [@BotFather](https://t.me/BotFather) في تلجرام
2. أرسل `/newbot`
3. اتبع التعليمات لإنشاء البوت
4. انسخ التوكن والصقه في التطبيق

#### 💰 Binance API
1. سجّل في [Binance](https://www.binance.com/)
2. اذهب إلى API Management
3. أنشئ API جديد
4. احفظ الـ API Key والـ Secret Key
5. الصقهما في التطبيق

⚠️ **تحذير**: استخدم مفاتيح Binance بقراءة فقط (Read-only) للحماية.

#### 🐙 GitHub Token
1. اذهب إلى [GitHub Settings → Tokens](https://github.com/settings/tokens)
2. أنشئ Personal Access Token (classic)
3. اختر الصلاحيات: `repo`, `read:user`
4. انسخ التوكن والصقه في التطبيق

#### 🎮 Discord Webhook
1. افتح Discord → إعدادات القناة → Integrations → Webhooks
2. أنشئ Webhook جديد
3. انسخ URL والصقه في التطبيق

### الذاكرة (تفضيلات المستخدم)

اضغط على أيقونة 🧠 (Brain) في الأعلى لإدخال تفضيلاتك:
- لغتك المفضلة (TypeScript, Python, إلخ)
- أسلوب الكتابة
- التقنيات المفضلة
- مستواك التقني

هذه التفضيلات تُحقن في كل محادثة لتخصيص الردود.

## الاستخدام

### الواجهة الرئيسية

1. **الـ Sidebar الأيمن**: قائمة المحادثات المحفوظة
2. **التصنيفات** (في الأعلى): برمجة / تداول / وسائط / محتوى / SEO / منصات
3. **تبويبات الأوضاع**: تختلف حسب التصنيف المختار
4. **الجزء الأيسر**: محرر الأكواد (Monaco) أو أدوات المنصات
5. **الجزء الأيمن**: لوحة الدردشة مع المساعد

### المهام الشائعة

#### تعديل كود
1. اختر تصنيف "برمجة" → وضع "تعديل"
2. الصق الكود في المحرر (أو ارفع ملفات)
3. اكتب التعديل المطلوب في الـ input
4. اضغط Ctrl+Enter للإرسال

#### توليد صورة
1. اختر تصنيف "وسائط" → وضع "توليد صور"
2. اكتب وصفاً بالعربية
3. اضغط إرسال (10-20 ثانية)

#### تحليل فيديو يوتيوب
1. اختر تصنيف "منصات" → وضع "YouTube تحليل"
2. اضغط على "تحليل فيديو"
3. الصق رابط الفيديو
4. احصل على الإحصائيات الكاملة

### اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|---------|---------|
| `Ctrl + Enter` | إرسال الرسالة |
| `Escape` | إغلاق الـ Dialog |

## استكشاف الأخطاء

### المشكلة: المنفذ 3000 مستخدم

**الحل**: عدّل `package.json`:
```json
"dev": "next dev -p 3001"
```

### المشكلة: فشل في تثبيت الاعتماديات

```bash
# احذف node_modules وأعد التثبيت
rm -rf node_modules
rm bun.lockb
bun install
```

### المشكلة: خطأ في قاعدة البيانات

```bash
# احذف قاعدة البيانات وأعد إنشاءها
rm -f db/custom.db
bun run db:push
```

### المشكلة: المفاتيح لا تُحفظ

- تأكد من تفعيل JavaScript في المتصفح
- تأكد من أن المتصفح يسمح بـ localStorage
- جرّب تصفحاً خاصاً للتأكد من عدم وجود إضافات تعرقل العمل

### المشكلة: أخطاء في Prisma

```bash
# أعِد توليد Prisma Client
bun run db:generate
```

## التقنيات المستخدمة

- **Frontend**: Next.js 16, React, TypeScript, Tailwind CSS 4, shadcn/ui
- **Backend**: Next.js API Routes, Prisma ORM, SQLite
- **محرر الأكواد**: Monaco Editor (نفس محرك VS Code)
- **الذكاء الاصطناعي**: Z.AI SDK (نموذج GLM)
- **الخطوط**: Cairo (عربي), JetBrains Mono (أكواد)
- **إدارة الحالة**: React Hooks, Event Emitters
- **البث**: Server-Sent Events (SSE)
